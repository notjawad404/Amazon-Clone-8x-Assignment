## How auth works
- **Token:** the server signs a JWT (`{ sub: userId }`, valid 7 days) and stores it in an httpOnly cookie, so it never appears in a response body or localStorage. Each request loads the user fresh from the database, so a deleted account or a role change takes effect immediately.
- **Passwords:** bcrypt with cost 12. Sign-up requires at least 8 characters with a letter and a number. An unknown email takes as long to reject as a wrong password, so timing doesn't reveal registered emails.
- **Rate limits:** 10 sign-in/sign-up attempts per 15 minutes per IP, plus a general API limit.
- **Validation:** unknown fields are rejected, so a client can't sign itself up as `admin`.
- **Admin pages:** `/admin/*` shows a 404 to anyone who isn't an admin; the server returns 403.

## Protected routes
