**What happens for each kind of user**

| | Signed-in user | Signed-out user |
|---|---|---|
| Where it's stored | One `carts` document per user in MongoDB (unique on `user`) | `localStorage` |
| On every change | That same document is updated (add, change quantity, save for later, delete) | `localStorage` is rewritten |
| Another device | Shows the same cart: device B saw exactly what device A had | — |
| Becomes empty | The document is deleted | The `localStorage` key is removed |
| At checkout | Bought items are removed; the document is deleted if nothing is left | They must sign in first, which merges the cart into the account and clears `localStorage` |

**Decision for you:** "Saved for later" items are kept when an order completes; only the bought items leave the cart. So the cart document is deleted after checkout only if nothing was saved for later. If you want checkout to always delete the whole cart, saved items included, it's a one-line change.
